# vnpy_autorepay

vnpy_autorepay是基于VeighNa量化交易框架开发的融资账户自动还款应用。该应用支持定时和间隔两种触发方式，能够自动执行融资账户的现金还款操作。

## 功能特性

- **融资账户管理**：支持添加、编辑、删除融资账户信息
- **还款任务配置**：支持定时执行和间隔执行两种触发方式
- **任务监控**：实时显示任务执行状态和历史记录
- **账户安全**：账户信息加密存储
- **执行日志**：详细记录所有还款操作
- **错误处理**：完善的错误处理机制和重试支持

## 安装方式

```bash
pip install vnpy_autorepay
```

## 使用说明

### 启动应用

在VeighNa Trader中启动自动还款应用：

1. 启动VeighNa Trader
2. 在菜单栏中选择"应用" -> "自动还款"
3. 打开自动还款管理界面

### 配置流程

1. **账户管理**：添加融资账户信息
   - 输入账户名称
   - 选择交易网关
   - 设置用户名和密码（加密存储）
   - 配置最大还款金额和最小保留余额

2. **还款设置**：创建还款任务
   - 选择触发方式（定时执行/间隔执行）
   - 设置执行时间或间隔
   - 关联融资账户

3. **任务监控**：查看执行状态
   - 实时监控任务执行状态
   - 查看历史执行记录
   - 查看操作日志

## 触发方式

### 定时执行
在每天固定时间执行还款操作，精确到分钟级别。

### 间隔执行
按照设定的时间间隔周期性执行还款操作，支持：
- 分钟级间隔
- 小时级间隔
- 天级间隔
- 周级间隔
